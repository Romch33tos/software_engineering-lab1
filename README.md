# ТЭО IT-проекта 

Веб-приложение для технико-экономического обоснования IT-проектов, позволяющее проводить комплексный расчет капитальных и эксплуатационных затрат, оценивать экономическую эффективность и сравнивать проект с его рыночным аналогом.

## Описание проекта

Приложение предоставляет инструмент для финансового анализа IT-проектов на ранних стадиях планирования. Расчеты базируются на методике оценки экономической эффективности с использованием коэффициента технического уровня (КТУ), приведенных затрат и интегральных показателей. Все вычисления выполняются на стороне клиента в реальном времени, с детализированным отображением формул и промежуточных результатов.

### Основной функционал

- **Базовые настройки** - задание окладов специалистов, налоговых коэффициентов, стоимости машино-часа и других исходных параметров
- **КТУ (коэффициент технического уровня)** - сравнительная оценка проекта и аналога по взвешенным показателям качества
- **План-график** - поэтапное планирование работ с расчетом человеко-дней и автоматическим вычислением дат завершения
- **Капитальные затраты** - расчет полной стоимости разработки с учетом ФОТ, налогов, накладных расходов и материалов
- **Эксплуатационные затраты** - оценка годовых расходов на сопровождение, включая амортизацию, электроэнергию и ремонт
- **Экономическая эффективность** - расчет приведенных затрат, годового экономического эффекта, срока окупаемости и фактического коэффициента эффективности
- **Итоговая таблица** - сводка всех ключевых показателей с аналитическими комментариями и выводами
- **Валидация данных** - проверка корректности всех вводимых значений с подсветкой ошибочных полей и навигацией к проблемным местам

## Технологии

- **HTML5** - семантическая разметка с поддержкой accessibility
- **CSS3** - адаптивная верстка с использованием Grid Layout, Flexbox и медиа-запросов
- **JavaScript (ES6+)** - модульная архитектура на чистом JS без внешних зависимостей
- **IIFE** - изоляция области видимости для предотвращения конфликтов в глобальном пространстве имен

## Запуск приложения

### Предварительные требования
Для работы с приложением не требуется установка дополнительного программного обеспечения или серверных сред (Node.js, Python и др.). Достаточно наличия современного веб-браузера с поддержкой стандартов ES6+:
- **Google Chrome** (версия 90+)
- **Mozilla Firefox** (версия 88+)
- **Apple Safari** (версия 14+)
- **Microsoft Edge** (версия 90+)
